# SON FREKANS

A 2D narrative-driven pixel art game developed as a solo project in Godot.

## Overview

SON FREKANS is a narrative-focused game built around exploration, environmental interaction, dialogue, and atmosphere.

The project focuses on creating a small, story-driven experience where the player discovers information by interacting with objects and the environment.

## My Role

**Solo Game Developer / Game Designer / Narrative Designer**

Responsible for:

- Game concept and direction
- Gameplay design
- Narrative structure
- Environmental interaction
- Dialogue and interaction systems
- UI interaction
- Godot implementation
- GDScript programming
- Scene and gameplay prototyping

## Core Systems

### Character Interaction

The player character can interact with objects and elements within the environment.

### Dialogue System

Interactive dialogue is used to deliver narrative information and connect environmental interactions with the story.

### Phone Interaction

A dedicated phone interaction system allows the player to access dialogue and narrative content through an in-game phone interface.

### Archive Interaction

The archive system provides another way for the player to discover and examine story-related information.

### Interactive Objects

Different environmental objects can trigger interactions, dialogue, or UI elements.

### Interaction UI

The project includes reusable interaction labels and interface elements to communicate available interactions to the player.

## Development

**Engine:** Godot  
**Language:** GDScript  
**Platform:** PC  
**Development:** Solo Project

## Technical Structure

The project is built using Godot's scene-based architecture.

Current development includes separate scenes and scripts for systems such as:

- Character
- Phone interaction
- Dialogue
- Archive interaction
- Interactive objects
- Chairs and environmental objects
- Interaction UI
- Mixer interaction
- Mixer interface

The project uses GDScript to connect gameplay logic, interactions, UI elements, and scene behavior.

## Design Focus

The main design goal of SON FREKANS is to connect **narrative and environmental interaction**.

Instead of relying only on traditional dialogue sequences, the player discovers information through objects, interfaces, and spaces within the game world.

This project represents an earlier stage of my development as a solo game developer and helped me build practical experience with Godot, GDScript, scene architecture, interaction systems, and narrative implementation.

## Current Status

The project is an independently developed prototype.

The repository contains the actual Godot project and its implemented gameplay systems.
